# lilypond

LilyPond sources for my scores and sketches. Rendered scores and recordings are at [zach.audio](https://zach.audio/compositions/).

Each piece is a top-level `.ly` file or a folder. Shared includes are in `definitions.ily` and `z/`. Start a new score from `template.ly`.

    lilypond summer.ly

Sources date from LilyPond 2.18–2.20; run `convert-ly` first on a current version.
