# archive/ — engraving sources lifted out of the media project folders

Each directory here is the `.ly`/`.ily` slice of a project that lives on
mandark under `~/Documents/Project Archive/` (and `~/Documents/Misc. Scores/`),
copied 2026-09-01 with its internal directory structure intact.

The source folders stay where they are. They are Ardour/Audacity/video project
trees — Siddhartha is 62 GB, Abecedarian 45 G, Brass Charts 2.4 G — and the
engraving sources are under 4 MB of that. Only the engraving comes here; the
media never does.

history is still only on mandark. Nothing here includes `lib/core` — the
shared engraving library is a separate lineage, used by `dog` and `abc`.
